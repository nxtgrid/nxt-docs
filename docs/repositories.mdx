# Repositories

This page tracks public NXT Grid repositories currently covered by this docs hub.

## Included repositories

- [nxt-backend](https://github.com/nxtgrid/nxt-backend) - Backend platform for mini-grid operations, payments, monitoring, and prepaid meter interactions.
- [nxt-sts](https://github.com/nxtgrid/nxt-sts) - Spring Boot microservice for IEC 62055-41 STS prepayment token generation.
- [nxt-topup](https://github.com/nxtgrid/nxt-topup) - Customer-facing PWA for prepaid meter top-ups and transaction history.
- [nxt-crm](https://github.com/nxtgrid/nxt-crm) - PWA dashboard for mini-grid developers and operators to monitor and manage sites.
- [nxt-field-ops](https://github.com/nxtgrid/nxt-field-ops) - Field technician PWA for installation, commissioning, and fault resolution workflows.
- [nxt-control-room](https://github.com/nxtgrid/nxt-control-room) - Operations dashboard for managing infrastructure, users, payments, and commissioning.
- [nxt-ui-components](https://github.com/nxtgrid/nxt-ui-components) - Shared Vue 3 components, composables, styles, and integration layers for NXT apps.
- [nxt-ai-assistant](https://github.com/nxtgrid/nxt-ai-assistant) - Chat orchestrator with Gemini, dynamic instructions, RAG, and MCP integration.
- [nxt-gis](https://github.com/nxtgrid/nxt-gis) - FastAPI geospatial backend for infrastructure planning and network optimization.
- [lorawan-cups-server](https://github.com/nxtgrid/lorawan-cups-server) - CUPS implementation for the Semtech binary protocol.
- [lorawan-cert-renewer](https://github.com/nxtgrid/lorawan-cert-renewer) - Automated TLS renewal and credential packaging for LoRaWAN infrastructure.
