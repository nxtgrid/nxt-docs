# nxt-topup

## Purpose

`nxt-topup` is the customer-facing application for prepaid meter top-ups and payment history.

## Scope

- Customer purchase and top-up journeys.
- Transaction visibility and account-level payment interactions.

## Key components

- Top-up/payment UI flows.
- API integration for balances, orders, and transaction records.
- Mobile-first PWA experience.

## Setup and run

- Repository: [github.com/nxtgrid/nxt-topup](https://github.com/nxtgrid/nxt-topup)
- Local setup and deployment details are maintained in the repository README.
