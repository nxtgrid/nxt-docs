# nxt-gis

## Purpose

`nxt-gis` provides geospatial analysis services for infrastructure planning in the NXT ecosystem.

## Scope

- Spatial analysis workflows for planning and optimization.
- APIs for geospatial computation and planning outputs.

## Key components

- FastAPI backend for geospatial endpoints.
- Spatial algorithms for pole placement and line routing.
- PostGIS-backed data and computation workflows.

## Setup and run

- Repository: [github.com/nxtgrid/nxt-gis](https://github.com/nxtgrid/nxt-gis)
- Local setup and runtime instructions are maintained in the repository README.
