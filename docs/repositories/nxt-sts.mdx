# nxt-sts

## Purpose

`nxt-sts` provides STS prepayment token generation compliant with IEC 62055-41.

## Scope

- Token generation and validation workflows.
- Service interfaces for prepaid utility metering integrations.

## Key components

- STS token generation logic.
- API endpoints for issuing tokens.
- Domain utilities around STS standard handling.
