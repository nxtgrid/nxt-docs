# nxt-backend

## Purpose

`nxt-backend` is the core backend platform for the NXT suite. It supports mini-grid operations across payments, monitoring, user management, and prepaid metering workflows.

## Scope

- Core business logic and APIs for platform operations.
- Integrations needed by operator apps and customer-facing applications.
- Metering and payment-related backend workflows.

## Key components

- API endpoints consumed by NXT applications.
- Domain services for operational and payment workflows.
- Data persistence and integration layers for connected systems.
