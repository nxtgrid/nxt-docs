# nxt-crm

## Purpose

`nxt-crm` is the operator-facing CRM/dashboard application for managing mini-grid sites and communities.

## Scope

- Operational visibility for infrastructure and customers.
- Site, hardware, and organization management workflows.

## Key components

- Dashboard and monitoring views.
- Administrative workflows for entities and records.
- Backend API integrations for operational data.

## Setup and run

- Repository: [github.com/nxtgrid/nxt-crm](https://github.com/nxtgrid/nxt-crm)
- Local setup and runtime instructions are maintained in the repository README.
