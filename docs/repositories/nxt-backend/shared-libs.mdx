# Shared libraries

Shared libraries provide reusable modules across `nxt-backend` applications.

## Libraries

- `libs/core` - shared NestJS modules and cross-cutting concerns (for example auth guards and alerting).
- `libs/helpers` - utility helpers and shared TypeScript functions.
- `libs/timeseries` - TimescaleDB integration utilities and shared query/connection concerns.
