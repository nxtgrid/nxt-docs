# nxt-ui-components

## Purpose

`nxt-ui-components` is the shared frontend component and integration library used across NXT applications.

## Scope

- Reusable UI components and composables.
- Shared styling patterns and integration helpers.

## Key components

- Vue 3 component library.
- Shared composables and utility abstractions.
- API integration helpers used by multiple frontend repos.

## Setup and run

- Repository: [github.com/nxtgrid/nxt-ui-components](https://github.com/nxtgrid/nxt-ui-components)
- Local setup, build, and release instructions are maintained in the repository README.
