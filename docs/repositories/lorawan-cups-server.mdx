# lorawan-cups-server

## Purpose

`lorawan-cups-server` provides CUPS functionality for LoRaWAN device configuration and updates.

## Scope

- CUPS protocol handling for configuration/update operations.
- Runtime generation of responses for compliant LoRaWAN infrastructure workflows.

## Key components

- Binary protocol parsing and response generation.
- Certificate/config distribution logic.
- Integration boundary with LoRaWAN network infrastructure.
