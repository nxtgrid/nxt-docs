# lorawan-cert-renewer

## Purpose

`lorawan-cert-renewer` automates certificate renewal and credential bundle preparation for LoRaWAN services.

## Scope

- Certificate renewal automation workflows.
- Packaging and delivery of updated credential bundles.

## Key components

- Renewal scheduling/execution scripts.
- Bundle generation for CUPS/LNS consumers.
- Operational integration with LoRaWAN certificate lifecycle.

## Setup and run

- Local setup and operational instructions are maintained in the repository README.
