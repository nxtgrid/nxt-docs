# nxt-field-ops

## Purpose

`nxt-field-ops` supports technicians in the field for installation, commissioning, and fault-resolution tasks.

## Scope

- Mobile workflows for onsite operations.
- Data capture and task execution during technical interventions.

## Key components

- Field task flows for install/commissioning.
- Fault and maintenance workflows.
- Backend API integrations for operational updates.

## Setup and run

- Repository: [github.com/nxtgrid/nxt-field-ops](https://github.com/nxtgrid/nxt-field-ops)
- Local setup and runtime instructions are maintained in the repository README.
