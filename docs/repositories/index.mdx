# Repositories

This page tracks public NXT repositories currently covered by this docs hub.

## Included repositories

- [nxt-ai-assistant](./nxt-ai-assistant) - Chat orchestrator with Gemini, dynamic instructions, RAG, and MCP integration.
- [nxt-backend](./nxt-backend) - Self-hostable NestJS/Nx backend (`api` + `worker`); features selected by JSON config.
- [nxt-control-room](./nxt-control-room) - Operations dashboard for managing infrastructure, users, payments, and commissioning.
- [nxt-crm](./nxt-crm) - PWA dashboard for mini-grid developers and operators to monitor and manage sites.
- [nxt-device-messaging](./nxt-device-messaging) - Standalone command-delivery service for field devices (plugins, Redis queue, signed webhooks).
- [nxt-field-ops](./nxt-field-ops) - Field technician PWA for installation, commissioning, and fault resolution workflows.
- [nxt-gis](./nxt-gis) - FastAPI geospatial backend for infrastructure planning and network optimization.
- [nxt-sts](./nxt-sts) - Spring Boot microservice for IEC 62055-41 STS prepayment token generation.
- [nxt-topup](./nxt-topup) - Customer-facing PWA for prepaid meter top-ups and transaction history.
- [nxt-ui-components](./nxt-ui-components) - Shared Vue 3 components, composables, styles, and integration layers for NXT apps.
- [lorawan-cert-renewer](./lorawan-cert-renewer) - Automated TLS renewal and credential packaging for LoRaWAN infrastructure.
- [lorawan-cups-server](./lorawan-cups-server) - CUPS implementation for the Semtech binary protocol.
