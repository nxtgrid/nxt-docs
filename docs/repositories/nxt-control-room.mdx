# nxt-control-room

## Purpose

`nxt-control-room` is the central operations dashboard for managing infrastructure, users, and operational workflows.

## Scope

- Real-time operational oversight.
- Management workflows for core infrastructure and platform entities.

## Key components

- Monitoring and control dashboards.
- Operations workflows across users, assets, and payment-linked processes.
- Integrations with backend APIs and operational services.
