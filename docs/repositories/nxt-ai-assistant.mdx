# nxt-ai-assistant

## Purpose

`nxt-ai-assistant` orchestrates AI chat behavior with dynamic instructions, retrieval, and tool integrations.

## Scope

- Chat orchestration and prompt/instruction handling.
- Retrieval-augmented responses and external tool connectivity.

## Key components

- Gemini-based orchestration pipeline.
- Dynamic system instruction sourcing.
- RAG knowledge retrieval and MCP tool integration.
