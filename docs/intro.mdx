# NXT Docs

This site is the central documentation hub for NXT Grid open-source projects.

## Scope

- Unified docs home for NXT Grid repositories.
- Clear links and concise project-level docs.
- Incremental updates reviewed before merge.

## Getting started

Run locally:

```bash
npm install
npm start
```

Build for production:

```bash
npm run build
```
