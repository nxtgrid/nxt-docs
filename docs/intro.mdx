# Overview

NXT is an open software suite for operating off-grid and mini-grid energy systems end to end.

It combines backend services, operator tools, field workflows, customer payment apps, and shared UI/integration layers into one ecosystem.

## What the suite covers

- Metering and prepaid token workflows (including STS).
- Customer top-up and account experiences.
- Operator dashboards for infrastructure and community management.
- Field operations for installation, commissioning, and fault resolution.
- Geospatial planning and optimization.
- Shared components and supporting infrastructure services.

## How to use this docs hub

- Start with `Repositories` to understand the role of each codebase.
- Use repository pages to find purpose, architecture, and setup links.
- Follow `Contributing` to propose and review documentation updates incrementally.

## Documentation approach

- Keep content practical and system-oriented.
- Prioritize cross-repo understanding over tool-specific internals.
- Evolve docs step by step as repositories and integrations mature.
